# Huawei Cloud Certified Developer – AI (HCCDA-AI)

**A 12-week learning repository covering Python, Machine Learning, Deep Learning, Hugging Face, and practical AI development.**

This repository brings together learning materials, hands-on code, exercises, and practical examples used throughout the **Huawei Cloud Certified Developer – AI** learning journey. It is designed to help students build a foundation in programming, understand core AI concepts, and gradually apply them to real-world problems.

The focus is on **learning by doing**: start with simple Python programs, explore data and machine learning, build deep learning models, and work with modern AI tools and cloud-based workflows.

## Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/YOUR_USERNAME/huawie-cloud-certified-developer-ai.git
cd huawie-cloud-certified-developer-ai
```

Replace `YOUR_USERNAME` with your GitHub username, and update the repository path if its spelling is different.

**2. Create a Python environment (recommended)**

```bash
python -m venv .venv
```

Activate it:

- **Windows:** `.venv\Scripts\activate`
- **macOS / Linux:** `source .venv/bin/activate`

**3. Install the required packages**

If a lesson or project includes a `requirements.txt` file, install its dependencies with:

```bash
pip install -r requirements.txt
```

Otherwise, follow the setup instructions in the relevant notebook or lesson.

**4. Explore the materials**

Open the lesson folder or notebook for your current topic. Read the explanation, run the examples, and complete the practice tasks. Jupyter notebooks can be opened in JupyterLab, VS Code, or another compatible notebook environment.

## Learning Outcomes

By working through the materials, students can develop the ability to:

1. Write and understand Python programs used in AI workflows.
2. Prepare, explore, and visualize datasets.
3. Build and evaluate basic machine learning models.
4. Understand neural networks and apply deep learning fundamentals.
5. Use pretrained models and tokenizers with Hugging Face.
6. Understand the basic workflow of developing and deploying AI applications on the cloud.

## How to Use This Repository

Follow the lessons in order if you're new to programming or AI. If you already know the basics, jump to the topic you want to practice. For each topic, **read → run → modify → practice**. Experimenting with the examples is one of the best ways to strengthen your understanding.
